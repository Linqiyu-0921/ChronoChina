# 此年 · ChronoChina

中国历史时序图谱：把任何一年，读成同时代政权、帝王、年号与史事的横向对照。

React 18 + TypeScript + Vite，数据为静态 JSON，无后端。

<https://github.com/Linqiyu-0921/ChronoChina>

---

## 怎么用

页头是七个入口，右侧另有一个明暗主题开关。

| 入口 | 用途 |
|---|---|
| 阅年 | 一年一页的阅读模式 |
| 并世 | 纵向多年对照（默认首页） |
| 朝代 | 展开时期与政权，直达开朝年 |
| 纪年资料库 | 全部年号总表，可筛选、导出 CSV |
| 历史遗产 | 文化遗产卡片，可回跳年代 |
| 搜索 | 年份、年号、干支、人物、政权的全局检索 |
| 关于本站 | 使用说明、覆盖范围与来源 |

### 阅年

把「这一年」当一页书读：汉字年份、公元年、干支、同为「同岁」的政权数同屏。

- 滚轮、`↑ ↓` 或上下滑动翻年；
- 每个并存政权是一张折页，点开看年号、君主、改元月份与区间备注；同年改元会分行列出；
- 「阅此年档案」打开年度档案：当年事件、同期纪年、在世与生卒人物；
- `Esc` 合上档案。

### 并世

以纵向时间画布比较同一时刻并立的政权。

- 中央朱红年份就是当前年，**滚动即选年**；点击它就输入年份（`1127`、`前221`）；
- 当年存续的政权各占一列，横向滑动看更多，底部 `‹ ›` 整组切换；
- 年号用括号线画真实起讫；区间太短放不下标签时用连线把标签引到空白处；
- 虚线括号 = 异说或约年；
- 「年档案」浮层：拖标题栏移动、八向手柄缩放、拖滑杆调纸面透明度，可固定到侧边读完整记录；
- `Ctrl / ⌘ + 滚轮` 或底部 `+ −` 缩放时间密度。

### 搜索

`Ctrl / ⌘ + K` 打开居中搜索浮层，输入即搜：

`1127`、`前221`、`建炎元年`、`绍兴`、`丁未`、`秦始皇`、`donghan`、`三国`……

`↑ ↓` 选择，`Enter` 定位，`Esc` 关闭。结果多时可「显示更多」。

### 明暗主题

右上角日月图标切换浅色（宣纸白）与暗色（墨底金字），选择会记住，版式与字号不变。

### 快捷键

| 按键 | 位置 | 作用 |
|---|---|---|
| `Ctrl / ⌘ + K` | 全局 | 打开 / 关闭搜索 |
| `↑ ↓` `Enter` `Esc` | 搜索 | 选择 / 定位 / 关闭 |
| `← →` | 并世 | 上一年 / 下一年（`Shift` 一次十年） |
| `↑ ↓` `PageUp` `PageDown` `Home` `End` | 并世年轴 | 移动年份 |
| `Ctrl / ⌘ + 滚轮`、`+ −` | 并世 | 缩放 |
| 滚轮、`↑ ↓`、上下滑动 | 阅年 | 翻年 |
| `Esc` | 阅年 / 档案 | 合上 |

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 数据校验 + 构建到 dist/
npm run preview    # 预览构建产物
```

改了 `data/*.json` 后跑 `npm run validate`（`build` 会自动跑），`npm test` 是回归测试。

纯静态站，`dist/` 可直接部署到 GitHub Pages / Cloudflare Pages / Vercel 等任意静态托管（`base: './'`，子路径也适用）。

## 数据

覆盖前 306 — 1911 年主要政权：36 个政权、242 位君主、540 个年号、753 条事件、78 位人物、82 处遗产。

- 纪元表来自《中国历代纪元表》脚本导入，干支与算法逐条互验；
- 事件参照维基《中国历史年表》整理并独立改写，人物生卒并入事件流；
- 每条纪年、事件、遗产都带来源，异说与约数显式标注；
- 十六国、十国尚未录入，西辽 1143 年之后待补；人物与遗产为精选，非完整名录。

来源：维基百科《中国历史年表》（CC BY-SA 4.0）、Y. T. Liu 中国历史纪年表、密西西比大学托管的历代纪元表、UNESCO 世界遗产与全国重点文保公开名录。
