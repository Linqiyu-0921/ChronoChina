# 此年 · ChronoChina

**此年，山河同阅。** —— 一个年份，横向读出同时代的政权、年号与史事。

![此年 ChronoChina 封面：水墨山水之上的时间轴，自夏至民国](docs/assets/cover.jpg)

## 创作初衷

读与历史相关的书籍、历史同人或正史时，经常会遇到这些问题：

- 「绍兴十二年是哪年？」——先要想起绍兴元年，再自己往后数十二年。
- 「丁未是哪年？」——干支六十年一轮，光看两个字，不知道落在哪一朝。
- 「乾贞元年谁在行用？」——翻过几卷朝代，才知道是吴的杨溥。

它们问的都不是「发生了什么」，而是「同一年里，谁在，各自怎么纪年」。史书按政权分卷书写，读者只能把散在不同卷次里的同一年，在脑子里重新摆成一行。

我平时做空间数据，习惯先把东西放进同一个坐标系：有原点、有尺度，位置才说得清。时间也该有这样一把尺子。这个站就先给年份，再把同年并立的政权、年号与史事摆在一行——能查、能对上、能翻到依据。

它不做地图，也不做装饰性的长卷。「此年，山河同阅」既是取景框，也是取舍：把「同时」还给历史，把判断留给你。尺子对齐了，规矩立住了，读史、学史才不烧心（bushi）。

## 怎么用

上面那三个问题，各查一次：

| 问题 | 操作 | 看到 |
|---|---|---|
| 绍兴十二年是哪年 | `Ctrl / ⌘ + K`，输入「绍兴十二年」 | 1142 年：宋绍兴十二年；同年金皇统二年、西夏大庆三年、西辽康国九年、大理广运 |
| 丁未是哪年 | 输入「丁未」 | 范围内所有丁未年（1127、1067、1007……），每六十年重复一次，任选一年进入 |
| 乾贞元年谁在行用 | 输入「乾贞」 | 927 年：吴·杨溥乾贞元年；同年后唐天成二年、吴越宝正、南汉白龙三年、辽天显 |

落到某一年，就是「阅年」：上下翻页换年份，横向读同期政权；点开任一政权，可见年号、君主、起讫与改元月份，下缘还能翻出「年度档案」，汇总当年史事、同期纪年与在世人物。要看连续多年的对照，切到「并世」。

## 核心功能

- **阅年** —— 一年一页：年份、干支与同年并立政权数；页首题记由当年改元自动生成（「丁未之年，五政权并立；赵宋改元建炎，西夏改元正德。」）；政权按都城由南向北编号，不预设谁是「正统」；展开可见年号、君主、起讫与改元月份；滚轮 / `↑ ↓` / 滑动翻年。
- **并世** —— 纵向多年对照：左栏公元纪年，中央朱红横线即当前年；当年存续政权各占一列展签，自南向北排列，年号按真实起讫画期间条，与当前年重合处展开年号、君主与改元月份；`Ctrl / ⌘ + 滚轮` 缩放时间密度，`‹ ›` 整组切换政权。
- **搜索** —— `Ctrl / ⌘ + K`：留空是朝代目录，点击时期或政权直达开朝年并保留同期比较；输入后检索年份（`1127`、`前221`）、年号与年次（`建炎元年`、`绍兴十二年`）、干支（`丁未`）、人物别名（`秦始皇`）与政权拼音（`donghan`）。
- **纪年资料库** —— 政权、君主、年号、起讫、干支、改元月份、异说与来源一表呈现，支持筛选与导出 CSV。
- **历史遗产** —— 162 处精选遗产，按类别 / 朝代 / 关键词筛选，可回跳始建年代。
- **年档案** —— 可拖动、可八向缩放、可调纸面透明度、可固定到侧栏的浮动记录，随当前年份更新；君主名可点开君主档案。
- **多语言界面** —— 简体 / 繁體 / English 三态切换，默认跟随浏览器语言、选择会被记住；繁体连史实数据一起转写，英文只译界面文案，政权、年号与事件保留中文原名。
- **明暗主题** —— 宣纸白 / 墨底金字，两套配色共用同一版式，只换纸墨不动版心；选择会被记住。
- **键盘与无障碍** —— 首行「跳到正文」直达主内容；`Esc` 关闭搜索与档案并把焦点交还原处；搜索为 `combobox`，方向键可选择。

此年不做疆域图。要看具体时期的疆域地图，请前往 [江山地图](https://deanchen.me/jiangshan-map/)。

## 数据与准确性

- 覆盖前 769—1911 年：90 个政权、1107 条纪年记录（其中 746 条有年号名），含春秋战国诸侯、十六国旁支、十国及十国之外的割据政权，以及吐蕃、南诏、回鹘、渤海、新罗、契丹等周边政权。
- 5345 条事件（覆盖 2200 个年份）、668 位精选人物、162 处遗产。
- 每条年号与事件附带来源；异说（`disputed`）与约年（`approx`）在界面以虚线与徽记区分；没收录的年份照实留白——空白不等于无史。
- 内部时间统一为天文纪年整数（前 1 = 0），干支由算法生成、不存进数据；改元月份按原记载标注，不自动换算公历日。
- 校验通过不等于史实审定：事件、人物与遗产仍待条目级复核。

## 本地运行

要求 Node.js 18+。

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 数据校验 + 构建到 dist/
npm run preview    # 预览构建产物
```

数据相关命令：

```bash
npm run validate   # 数据校验（改 data/*.json 后必跑，build 会自动执行）
npm test           # 日期、换算、搜索与档案布局回归测试
```

## 项目结构

| 路径 | 用途 |
|---|---|
| `data/` | 静态数据：政权、君主、年号、事件、人物、遗产、来源 |
| `data/curated/` | 手工校订覆盖层，优先级最高 |
| `scripts/` | 数据导入、校验与回归测试 |
| `src/views/` | 阅年、并世、纪年资料库、历史遗产 |
| `src/components/` | 搜索浮层、年档案、年份面板、君主档案、分类筛选 |
| `src/lib/` | 数据访问、时间与干支、搜索、换算 |
| `src/styles.css`、`src/reading-collections.css` | 全局版式与册页、资料库样式 |
| `public/` | 字体、图标原稿、站点图标 |
| `docs/preview/` | README 界面预览图 |
| `docs/assets/` | README 与对外展示用封面图 |

## 开发计划

**已完成**

- 前 769—1911 年主要政权纪年：90 个政权 / 825 位君主 / 1107 条纪年，干支与算法逐条互验；
- 十六国旁支（冉魏、西燕、翟魏、代）、十国之外的岐、桀燕、清源军、归义军，以及吐蕃、南诏、回鹘、渤海、新罗、契丹等周边政权；
- 5345 条事件与 668 位人物生卒联动，162 处精选遗产；
- 阅年历书册页、并世纵向对照、纪年资料库、历史遗产、玻璃搜索、年档案与君主档案；
- 明暗双主题同版式，数据校验与回归测试。

**计划中**

- 补录仍缺的短命政权与地方割据年号；
- 纪年条目级的来源复核与异说补注；
- 遗产名录向全国重点文保全量扩展，并做坐标联动（不自建疆域图，疆域外链江山地图）；
- 农历与公历的月级换算。

## 贡献指南

- **反馈问题**：在 [Issues](https://github.com/Linqiyu-0921/ChronoChina/issues) 说明现象、浏览器与复现步骤；史实问题请附来源。
- **提交修改**：Fork 后开分支，改动尽量单一；涉及 `data/*.json` 必须先跑 `npm run validate`，提交前跑 `npm run build` 与 `npm test`。
- **史实准则**：不接受无来源的纪年改动；异说须标注 `disputed` 并写明依据；不把农历日期自动换算成公历日。
