## 这是什么

这是一个**纪年工作台**：任何一年，都能同时回答「公元几年、干支为何、哪些政权并立、各自行用什么年号、当年发生了什么」。

它建立的是一个**统一的历史时间坐标系**——

- 公元纪年为唯一纵轴，前 1 年 = 0（天文纪年），无公元 0 年；
- 干支、年号、在位数由同一套规则计算与校验，不靠人工对表；
- 每条纪年、事件、遗产都可追溯到来源，异说与约数显式标注；
- 全部数据为**构建期静态 JSON**，无后端、无数据库、无运行时请求。

它**不是**地图集（史地联动仅深链外部地图，不自建疆域图），也**不是**展示型年表——不做装饰性时间轴，只做能核对、能定位、能追溯的阅读工具。

当前覆盖：**前 306 — 1911 年**主要政权纪年，36 个政权、242 位君主、540 个年号、753 条历史事件、78 位人物、82 处文化遗产。

## 界面与功能

整体采用「一页编年书」版式：单行页头 + 一个主画布 + 按需展开的档案。页头一级导航为七枚线稿图标，依次是：

| 图标 | 入口 | 说明 |
|---|---|---|
| 册页 | **阅年** | 一年一页的阅读模式 |
| 横列 | **并世** | 纵向多年对照（默认首页） |
| 楼阁 | **朝代** | 展开时期与政权菜单，直达开朝年 |
| 卷轴 | **纪年资料库** | 年号总表，可筛选、可导出 |
| 鼎 | **历史遗产** | 遗址卡片，可回跳年代 |
| 镜 | **搜索** | 全局检索浮层（`Ctrl / ⌘ + K`） |
| 山河 | **关于本站** | 阅读说明、覆盖范围与来源目录 |
| 日月 | **明暗主题** | 浅色宣纸 / 墨底金字，记忆选择 |

### 阅年 · 一年一页

把「这一年」当成一页书来读：

- 汉字大写的年份（如「一一二七」）、公元年、干支、同年并存政权数同屏呈现；
- 上下翻页：滚轮、`↑ ↓`、按钮或触摸上下滑动，一页一年；
- 「并存于此年」逐政权折页：当前行用年号、君主、改元月份与区间备注，点开即展开，且**同年改元分行列出**，不假装全年只用一号；
- 「这一年 · 历史纪事」摘取当年首条事件，可打开**年度档案**：事件、同期纪年、当年在世与生卒人物一次看全；
- 年度档案为侧边抽屉，`Esc` 合上并把焦点还给年份按钮。

### 并世 · 纵向多年对照

以纵向时间画布回答「同一时刻谁与谁并立」：

- 中央朱红年份指针固定，**滚动即选年**；点击年份可直接输入 `1127` 或 `前221`；
- 仅展示当前年份仍存续的政权列，列宽按可用宽度均分，横向滚动 + 前后整组切换；
- 年号按真实起讫绘制括号线，标出端点；区间过短、放不下标签时用连接线把标签引到空白处，不重叠、不丢失；
- 异说用虚线括号、约年用标记区分，不单靠颜色；
- **年档案**浮层：玻璃笺注风格，可拖动标题栏或方向键微调位置，八向手柄缩放（四边四角），纸面不透明度 45–100% 可调，可一键固定到侧栏读完整档案；
- 缩放：`Ctrl / ⌘ + 滚轮` 或底部 `+ −`，密度 0.25–100 px/年；
- 键盘：`↑ ↓`、`PageUp / PageDown`、`Home / End` 在年份滚动面上移动。

### 朝代菜单

秦汉、三国两晋、南北朝、隋唐五代、宋辽金夏元、明清六个时期分组列出全部政权，点击时期或政权即跳至开朝年，并同时设定该时期的比较时段。

### 纪年资料库

传统学术表格形态：政权、君主（可跨君主沿用）、纪年名称、起年、元年干支、末年、涉及年份数、改元月份、备注 / 异说、来源。支持关键词筛选、按政权过滤，以及**导出 CSV**（UTF-8 BOM，Excel 直接打开不乱码）。点击年号回到该年纪年起点。

### 历史遗产

82 处精选遗产卡片，覆盖聚落、都城、陵墓、宫殿、工程、军事、石窟、宗教、手工业、园林十类。支持按类别、朝代、关键词筛选；显示世界遗产登录年份、坐标、关联政权与来源，并可一键定位到始建年代。

### 全局搜索

`Ctrl / ⌘ + K` 打开居中玻璃浮层，输入即搜：

- 年份：`1127`、`前221`、`-221`；
- 年号纪年：`绍兴`、`靖康二年`、`建炎元年`、`天会13年`——带年次直接定位该年，不带年次列出同名年号；
- 干支：`丁未`，返回覆盖范围内所有候选年；
- 人物：姓名、名、号、别名（如「秦始皇」「嬴政」）；
- 政权拼音与片段：`donghan`、`shuhan`、`三国`；
- 事件与遗产名称片段，按「完全匹配 → 前缀 → 包含 → 模糊子序列」排序，模糊命中会标注。

结果支持 `↑ ↓` 选择、`Enter` 定位、`Esc` 关闭；超过 20 条可继续加载。

### 关于本站

一页容纳使用说明、覆盖范围与来源目录：哪些政权尚未录入、哪些纪年待复核、每条来源的许可与用途。页脚「查看来源与覆盖范围」直接跳到该页对应段落。

### 明暗主题与可访问性

- 顶部日月图标切换主题，`localStorage` 记忆（键名 `chronochina-original-theme`），默认暗色；
- 暗色**沿用同一版式**，只替换为墨底金字配色，布局、字号、当前年份均不变；
- 图标为 `currentColor` 描边的内联 SVG，常态取铜金色（`#a3824e`），悬停与当前页转为强调色；
- 主要按钮均有 `aria-label` / `aria-expanded` / `aria-current`，弹出层为原生 `<dialog>` 或带 `role` 的区域，搜索框用 `combobox + listbox` 语义，`prefers-reduced-motion` 下关闭入场动画。

## URL 状态参数

页面状态实时写入查询串（`history.replaceState`），可直接分享或刷新：

| 参数 | 取值 | 说明 |
|---|---|---|
| `view` | `timeline` / `table` / `sites` / `about` | 当前视图，缺省 `timeline` |
| `year` | 整数（前 1 = 0） | 当前年份 |
| `from` / `to` | 整数 | 比较时段端点 |
| `q` | 字符串 | 当前检索词 |
| `event` | 事件 id | 打开指定事件的年度档案 |
| `view=sources` | — | 旧链接兼容，自动落到「关于本站」 |
| `view=convert` | — | 旧链接兼容，直接打开搜索浮层 |

示例：`?view=timeline&year=1127&from=1100&to=1150&q=建炎`

## 数据

### 规模

| 数据集 | 条目 | 范围 | 说明 |
|---|---|---|---|
| `polities.json` | 36 个政权 | 前 306 — 1911 | 主要政权，非全部割据政权 |
| `reigns.json` | 242 位君主 | 同上 | 在位区间，可与年号区间分离 |
| `eras.json` | 540 个年号 | 同上 | 4 条标注异说，1 条跨君主沿用 |
| `events.json` | 753 条事件 | 前 295 — 1911 | 覆盖 555 个年份，非逐年齐全 |
| `persons.json` | 78 位人物 | 生卒纪年 | 73 位有确切生年 |
| `sites.json` | 82 处遗产 | 史前 — 清 | 其中世界遗产 40 处 |
| `sources.json` | 5 类来源 | — | 每条纪年 / 事件 / 遗产均引源 |

### 时间与纪年规则

1. **天文纪年整数**：前 1 年 = 0，前 2 年 = −1；禁止用 JS `Date` 表示历史年份。
2. **干支不落库**：全部由 `src/lib/time.ts` 的算法生成，并与校验脚本中的锚点交叉核对。
3. **在位与年号分离**：一个年号可跨君主沿用（`crossReign: true`，列出全部 `reignIds`）。
4. **同年改元**：前后年号允许相接（`next.start === prev.end`），但必须有 `startMonth`、`endNote` 或 `note` 佐证。
5. **异说与约数**：`disputed` / `precision: "approx"` 显式标注，界面以虚线、徽标与文字同时说明。
6. **月份即记载**：只到年级精度时不填月份；不把农历日期自动换算为公历日。
7. **来源必填**：每条 `era` / `event` / `site` 必须带 `sources`，新增来源先登记 `sources.json`。

### 校验

`npm run validate`（`npm run build` 会自动执行）检查：ID 唯一性、政权 / 在位 / 年号区间一致性、年号连续与重叠、跨君主引用完整、干支锚点、事件与遗产字段完整性。

`npm test` 为纯 Node 回归：日期边界、无公元 0 年、纪年越界、同名年号、干支候选、事件合并、来源必填、搜索直达，以及年档案四边四角缩放与视口约束。

## 快速开始

要求 Node.js 18+（建议 20 LTS）。

```bash
npm install
npm run dev        # 开发服务器，默认 http://localhost:5173
npm run build      # tsc 类型检查 + 数据校验 + 生产构建（dist/）
npm run preview    # 预览构建产物
npm run test       # 回归测试
npm run validate   # 单独跑数据校验（改数据后必跑）

# 幂等的数据重建脚本
node scripts/import-era-table.mjs   # 《中国历代纪元表》→ polities / reigns / eras
node scripts/import-events.mjs      # 维基年表 + 人物生卒 + 手工校订 → events
```

## 部署

纯静态站点，`dist/` 可直接部署到 GitHub Pages、Cloudflare Pages、Vercel 或任意静态服务器。

`vite.config.ts` 中 `base: './'`，资源路径为相对路径，因此部署在子路径（如 `用户名.github.io/ChronoChina/`）也无需改动配置。

## 设计说明

- **一页编年书**：只有一个主画布。页头紧凑、字号与列宽固定、详情按需展开，不堆叠操作栏、卡片与图例。
- **纸墨配色**：浅色为宣纸白底、墨青文字、朱砂强调当前年份；暗色为墨底、金字、暖棕分隔线，版式完全一致。
- **纪年可视化**：年号是一段真实区间，就用括号线画它；区间太短放不下标签时，用连接线把标签引到最近的空白，而不是直接省略。
- **图标**：一级导航为手绘矢量的线稿图标（册页、横列、楼阁、卷轴、鼎、镜、山河），取自项目描金线稿的造型意象后重新绘制为内联 SVG；界面**不加载** `public/assets/icons/gold-outline/` 下的位图原稿——那一组 34 枚 1254px 透明底线稿作为设计素材保留在仓库内，供后续海报、图标动画等使用。
- **搜索浮层**：居中于视口，半透明纸面 + `backdrop-filter` 模糊与饱和，暗色下同为深纸底金字；点击浮层外或 `Esc` 关闭。
- **不靠颜色传达含义**：异说、约年、缺录同时使用文字、虚线或徽标。

## 已知边界

- **政权覆盖**：十六国、十国尚未录入；西辽 1143 年之后纪年待补录；南明为补录条目。
- **事件密度**：按维基年表整理，753 条覆盖 555 个年份，空白年份只表示未收录，不表示无史事；`polityIds` 为按年份的粗略关联。
- **人物与遗产为精选**：78 位人物、82 处遗产（全量文保 5000+ 处）均非完整名录；人物以生卒纪年与一句话事迹为主。
- **无精确日期**：多数条目精确到年或月，不做农历—公历逐日换算。
- **校验 ≠ 审定**：脚本通过说明结构自洽，不代表史学结论；4 条年号标注异说，其余仍待条目级复核。

## 开发约定

项目级规则见 [`AGENTS.md`](AGENTS.md)，要点：

- 数据准确性优先于功能数量：宁可范围小，不可纪年错；
- 改任何 `data/*.json` 后必须 `npm run validate`，校验不过不许构建；
- 干支只由算法生成，不在数据中落库；新锚点写进 `scripts/validate.mjs`；
- 扩朝代按「一个政权一批」：先 `polities` / `reigns`，再 `eras`，最后 `events`；
- 新视图放 `src/views/`，共用查询逻辑放 `src/lib/`；版式变量集中在 `styles.css` 的 `:root`；
- 小步、可回滚、可解释的修改；重大方向调整先更新本 README。

交接手册见 [`docs/HANDOFF.md`](docs/HANDOFF.md)（数据操作流程、验收基线、历史迭代记录）。
