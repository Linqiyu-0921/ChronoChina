# 同岁山河 · ChronoChina

中国历史时序图谱。岁月同流，山河异纪。

> 可缩放、可检索、可追溯来源的**中国历史多政权并行年表与纪年研究工具**。
> 不是地图集，也不是展示型年表——核心价值是「统一历史时间坐标系」：任何时刻都能同时回答
> 公元年、干支、年号纪年、在位君主、同期各政权纪年，以及当年发生了什么。

**交接与进度文档见 [docs/HANDOFF.md](docs/HANDOFF.md)**（含数据管线操作手册、待办清单、验收基线）。

## 当前状态（v0.4.0）

当前界面采用「一页编年书」：单行页头、纵向时间主画布、按需展开的档案。朝代按时期分组、政权一步直达；纪年资料库、历史遗产与关于本站在一级导航直达，使用说明与来源覆盖合并为同一页面；一级导航为五枚 SVG 线稿图标（楼阁、卷轴年表、青铜鼎、镜、山河），仿本站描金线稿造型以矢量绘制、随明暗主题变色，不引用位图；搜索以中央浮层呈现，支持 Ctrl / Command + K、方向键选择、纪年换算、姓名片段和政权拼音。当前年份可直接编辑，同期政权按可用宽度分配完整列，横向滚动贴齐并支持前后整组切换，年号与帝王沿真实纪年区间排版，端点与起讫年份对应，短区间通过连接线标注。上下滚动选年，Ctrl / Command + 滚轮缩放时段；事件通过本年入口查看，不再常驻侧栏。

视觉定位：宣纸白与墨青为主，朱砂强调当前年份。保留清晰文字与必要的时间细线，完整日期、来源和争议说明进入详情。维持静态数据架构。

前轮重设计：时序工作台以 1100–1150 年为默认视窗，增加时段与缩放控制、全局分类检索、来源与覆盖说明、日期统一展示和 URL 状态恢复。维持静态数据架构；数据仍为主要政权覆盖，非全量史实库。

- **纪元数据**：秦至清主要政权（前 306—1911，部分缺录），36 政权、242 位君主、540 个年号。
  由《中国历代纪元表》脚本化导入（`scripts/import-era-table.mjs`），表内干支列与算法引擎
  **逐条互验 527 行 0 不符**；手工校订层（`data/curated/`）覆盖宋辽金夏西辽大理与南明补录。
- **事件数据**：全史 753 条（前 296—1911，覆盖 555 个年份）——维基《中国历史年表》
  脚本化导入（`scripts/import-events.mjs`）+ 人物生卒 + 手工校订层；六类启发标注（军事/政治/外交/制度/文化/人物）。
- **人物数据**：78 位历代名人（生卒天文纪年、领域、一句话事迹），年份面板显示「当年在世人物」与生卒提示，生卒自动并入事件流。
- **遗产数据**：82 处文化遗址种子（史前—清，含坐标、类别、世遗年份），见「遗产」视图。
- **四个视图**：
  1. **时间轴**：纵向滚动、中央年份指针、同期政权固定宽度比较；Ctrl / Command + 滚轮缩放，点击年份输入，朝代菜单定位开朝年。人物与年号按需展开；年份线上可展开悬浮笺注，并可固定到侧边，随当前年份更新；笺注支持拖动标题栏、方向键微调位置与纸面不透明度调节，以及四边、四角拖拽缩放；浮层随视口收窄自动约束位置和尺寸。
  2. **纪年检索**：`1127` / `前221` / `靖康二年` / `建炎元年` / `天会13年` / `丁未` 双向换算 + 当年人物。
  3. **纪元表**：传统学术表格（君主、年号、干支、改元月份、异说、来源），筛选 + CSV 导出。
  4. **遗产**：按类别/朝代/关键词筛选遗址卡片，可跳转时间轴定位始建年代。

## 启动

```bash
npm install
npm run dev        # 开发（Vite）
npm run build      # 类型检查 + 数据校验 + 构建（dist/）
npm run preview    # 预览构建产物
npm test           # 日期 / 换算边界 / 去重回归
npm run validate   # 数据校验（改数据后必跑）
node scripts/import-era-table.mjs   # 纪元表重导入（幂等）
node scripts/import-events.mjs      # 事件库重导入（幂等：curated + 维基年表 + 人物生卒）
```

纯静态站，无后端、无数据库；`dist/` 可直接部署 GitHub Pages / Cloudflare Pages。

## 数据管线

```
data/raw/lidaijiy.htm（原始表，勿改）
        │  scripts/import-era-table.mjs（rowspan 网格 + 干支锚定解析）
        ▼
生成层 polities/reigns/eras ──合并── data/curated/（手工覆盖，优先级最高）
        ▼
data/*.json ── scripts/validate.mjs（区间/连续性/引用/干支锚点/遗产字段）
        ▼
src/（构建期静态读取，无运行时数据库）
```

**时间规则**：内部统一天文纪年整数（前 1 年 = 0，无公元 0 年）；干支由算法计算不落库；
在位与年号分离建模（跨君主沿用 `crossReign`）；同年改元允许相接（须月份/备注佐证）；
异说条目 `disputed`/`approx` 显式标注并以虚线呈现。详见 HANDOFF §4。

**已知边界**：十六国与十国待 curated 补录；武周年号系于唐纪（表源如此，有备注）；南明为补录；
事件为维基年表密度（并非每一年都有条目）且 polityIds 系年份粗关联；人物库为精选 78 位非全量；
遗产为精选非全量（全量 5000+ 文保见 HANDOFF 待办）。

## 设计原则

以公元纪年为纵轴，以同期政权为并列列，以年号区间为细线，以当前纪年为阅读重点。采用「一页编年书」排版：紧凑页头、固定字号与列宽、按需详情，不重复堆叠操作栏、卡片和图例。宣纸白与墨青构成主体，朱砂强调当前年份；异说与约年同时使用文字与虚线说明，不只依赖颜色。

明暗主题：顶部明暗图标切换并记住选择；暗色沿用同一「一页编年书」版式，仅替换为墨底金字的配色，布局、字号与当前年份均不改变。
