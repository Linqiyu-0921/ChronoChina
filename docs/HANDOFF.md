## 0. 一句话现状

ChronoChina 是「纪年工作台」型的中国历史时序图谱：**v0.3.0 已完成秦至清全量纪元数据（36 政权 / 242 在位 / 540 年号，干支互验 0 不符）+ 全史事件库 755 条（维基年表导入 前296–1911 + 78 位人物生卒 + 手工校订层）+ 82 处遗产 + 四个视图**。构建与数据校验全绿；0.2.0 视觉验收已过、UI 已重设计为极简学术风（见 §5 第三、四轮）。

## 1. 快速上手

```bash
cd "02_产品项目/其他产品原型/ChronoChina"
npm install          # 依赖已装过可跳过（react18 / d3-scale / vite5 / cheerio 为 devDep）
npm run validate     # 数据校验（改数据后必跑）
npm run dev          # 开发服务器
npm run build        # tsc 类型检查 + 校验 + 构建 dist/
```

纯静态站，无后端无数据库；`dist/` 可直接部署 GitHub Pages / Cloudflare Pages。

## 3. 核心设计决策（为什么这么做）

1. **统一时间坐标**：内部全部用天文纪年整数（前 1 年 = 0，前 221 = −220），杜绝「无公元 0 年」偏移 bug；干支只算不存（`time.ts` 单一事实来源）。
2. **在位与年号分离**（Reign / EraUse 两实体）：支持「天会跨金太宗、熙宗两朝」「乾化两段复用」等形态。
3. **数据管线而非手抄**：纪元全量数据由 `import-era-table.mjs` 从原始 HTML 生成，表内**干支列与算法引擎逐条互验（527 行 0 不符）**；使用年数越界自动截齐并留报告。手工层（curated）只做覆盖与补录。
4. **curated 优先合并**：政权按 id 整条覆盖；年号按 `政权+年号名` 覆盖（同名生成段若与 curated 时段重叠则删除）；君主按 `政权+庙号+起始年` 对齐换绑。
5. **异说显式化**：`disputed` / `precision: approx` + note（西辽延庆起年三说、大理全推定、永历起年二说等），界面用虚线色带/徽标呈现，绝不假装精确。
6. **HistoryAxis 借鉴点**（v0.2 落地）：键盘 ←→ 步进选年、全史概览条导航、远中近三档 LOD（远景只看政权带，≤120 年才出君主层与事件层）、克制的灰阶装饰。差异化：我们是多政权并行的信息密度，它是极简单轴。

## 4. 数据管线操作手册

### 重跑导入（幂等）
```bash
node scripts/import-era-table.mjs && node scripts/validate.mjs
```
输出报告四项要盯：**干支互验不符（必须为 0）**、年数截齐（人工抽查）、缺年数、跳过行（应只剩 五帝/夏/商/西周/东周 + 民国/共和国 + 空标题行 ≈ 125 条）。

### 改一条年号数据
改 `data/curated/eras.json`（同 `polityId+name` 会覆盖生成值）→ 重跑导入。要改君主/政权同理（curated 政权的起讫是**钉死的**，不会被生成层重算）。

### 加一个新政权（如十六国/十国）
1. `scripts/import-era-table.mjs` 的 `POLITY_CFG` 加 `{id, name, color}`（原始表没有他们的行，所以走 curated）；
2. `data/curated/` 三文件补条目；
3. 重跑导入 + 校验。

### 加事件 / 加人物 / 加遗产
- **事件**：改 `data/curated/events.json`（生成层之上，同年前 10 字撞题会覆盖自动条目）→ `node scripts/import-events.mjs` → validate；
- **人物**：`data/persons.json` 追加（id/name/birth/death 天文纪年/polityIds/field/summary）→ 重跑 import-events（生卒自动入事件流）；
- **遗产**：直接编辑 `data/sites.json`（手工文件，无导入层）。事件字段必须有 `sources`；遗产必须有年代三选一（`builtYear`/`builtRange`/`period`）与 `place`。

### 解析器已知坑（改动前必读）
- 原表行首有「时代列 + 政权列」双前缀，格式含 `辽[耶律氏](907-1125)`、`秦[秦帝国(...)]` 等变体——`markerKey` 靠首个 `（[(【` 前的头部匹配；
- 对齐用**干支锚定法**（找到干支两字列再向两侧推定各列），免疫 colspan 空位与 rowspan 错位（王莽行名号空、宣统行、隋唐首行等）；
- 原表笔误已内置修正：清「世宗福临→世祖」「圣宗玄烨→圣祖」「奕苎→奕詝」、石敬塘→石敬瑭、赵韅→赵㬎、北魏「巳酉→己酉」；
- 王莽续行靠「当前君主归属」规则归入新朝（行首仍标西汉）；
- 同年同号多段（乾化/天福/乾祐/显德/天祐/永安）是**正确建模**，ID 自动加序号后缀。
